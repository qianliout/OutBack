# PostgreSQL 快速上手与常用操作指南

本文档总结了 PostgreSQL (简称 PG) 的高频用法，适合快速入门和日常备查。

## 1. 命令行基础操作 (psql)

- 连接数据库: psql -U 用户名 -d 数据库名 -h 主机地址 -p 端口
- 列出所有数据库: \l
- 切换/连接到指定数据库: \c 数据库名
- 列出当前数据库中的所有表: \dt
- 查看指定表的结构: \d 表名
- 退出 psql 命令行: \q

## 2. 数据库与表结构管理 (DDL)

创建数据库:
```sql
CREATE DATABASE my_database;
```

创建表 (包含常见数据类型与主键):
```sql
CREATE TABLE users (
    id SERIAL PRIMARY KEY,
    username VARCHAR(50) NOT NULL UNIQUE,
    email VARCHAR(100) NOT NULL,
    age INT DEFAULT 18,
    is_active BOOLEAN DEFAULT true,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

修改表结构:
```sql
-- 添加列
ALTER TABLE users ADD COLUMN phone VARCHAR(20);

-- 修改列类型
ALTER TABLE users ALTER COLUMN age TYPE SMALLINT;
```

删除表:
```sql
DROP TABLE IF EXISTS users;
```

## 3. 数据增删改查 (DML)

插入单条数据并返回 ID:
```sql
INSERT INTO users (username, email) VALUES ('alice', 'alice@example.com') RETURNING id;
```

批量插入数据:
```sql
INSERT INTO users (username, email) VALUES 
('bob', 'bob@example.com'),
('charlie', 'charlie@example.com');
```

更新数据:
```sql
UPDATE users SET age = 25, is_active = true WHERE username = 'alice';
```

删除数据:
```sql
DELETE FROM users WHERE age < 18;
```

基础查询 (带排序与分页):
```sql
SELECT id, username, email FROM users 
WHERE is_active = true 
ORDER BY created_at DESC 
LIMIT 10 OFFSET 0;
```

## 4. PostgreSQL 特色高级用法

冲突时更新 (Upsert - 必须有唯一约束或主键):
```sql
INSERT INTO users (id, username, email) 
VALUES (1, 'alice', 'new_email@example.com') 
ON CONFLICT (id) 
DO UPDATE SET email = EXCLUDED.email;
```

JSONB 数据类型操作 (PG 的杀手级功能):
```sql
-- 查询 JSON 内部的字段 (返回带引号)
SELECT info->'city' FROM users;

-- 查询 JSON 内部的字段 (返回纯文本)
SELECT info->>'city' FROM users;

-- 过滤 JSON 数据
SELECT * FROM users WHERE info->>'city' = 'Beijing';
```

通用表表达式 (CTE / WITH 语句，提高可读性):
```sql
WITH active_users AS (
    SELECT * FROM users WHERE is_active = true
)
SELECT * FROM active_users WHERE age > 20;
```

窗口函数 (常用于分组排名):
```sql
SELECT username, age, 
ROW_NUMBER() OVER (PARTITION BY is_active ORDER BY age DESC) as rank 
FROM users;
```

## 5. 索引与性能分析

创建普通索引:
```sql
CREATE INDEX idx_users_email ON users(email);
```

创建唯一索引:
```sql
CREATE UNIQUE INDEX idx_users_username ON users(username);
```

分析查询执行计划 (排查慢查询必备):
```sql
EXPLAIN ANALYZE SELECT * FROM users WHERE email = 'alice@example.com';
```

## 6. 备份与恢复

- 导出整个数据库: pg_dump -U 用户名 -d 数据库名 -f backup.sql
- 恢复数据库: psql -U 用户名 -d 数据库名 -f backup.sql
