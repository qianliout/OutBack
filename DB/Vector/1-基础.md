# 第一部分：向量数据基础

本部分将带你从零开始理解向量数据的本质，掌握向量嵌入（Embedding）的基本原理、常见模型、距离度量方法以及高维空间的特性。这些知识是深入学习向量数据库的基石，尤其对于理解后续索引构建、近似搜索和性能优化至关重要。

---

## 1. 向量嵌入的本质：从文本/图像到高维空间

### 原理讲解

向量嵌入（Vector Embedding）是一种将**非结构化数据**（如文本、图像、音频、视频）映射到**高维连续向量空间**中的数学表示方法。在该空间中，语义或视觉上相似的数据点在向量空间中的距离更近，而差异大的数据则相距更远。

- **向量**：一个由浮点数构成的数组，如 `[0.12, -0.45, 0.89, ..., 0.33]`，长度为维度（dimension），常见维度为 768、1024、1536 等。
- **嵌入过程**：通过深度神经网络（如 Transformer、CNN）将原始数据编码为固定长度的向量。
- **语义保留**：向量空间中，相似内容的向量具有较小的夹角或欧氏距离。

> 📌 **类比理解**：想象一个“语义地图”，其中“猫”和“狗”的位置接近，“猫”和“汽车”则相距较远。这个地图就是由嵌入模型构建的向量空间。

### 常见应用场景

| 数据类型 | 示例 | 嵌入模型 |
|--------|------|---------|
| 文本 | 句子、段落、文档 | BERT, Sentence-BERT, OpenAI Embeddings |
| 图像 | 图片、截图 | CLIP, ResNet, ViT |
| 音频 | 语音片段 | Wav2Vec, Whisper |
| 多模态 | 图文对、音视频 | CLIP, Flamingo |

## 2. 常见 embedding 模型简介

### (1) 文本嵌入模型

#### ✅ **BERT / Sentence-BERT (SBERT)**

- **来源**：Google（2018），SBERT 由 Sentence-Transformers 库优化
- **特点**：
  - 基于 Transformer 架构
  - 支持上下文感知的词义理解（如“苹果”在“吃苹果” vs “苹果公司”中不同）
  - SBERT 专门优化了句子级语义相似度任务，适合向量数据库使用
- **推荐开源模型（适合 M1 本地运行）**：
  ```bash
  # 使用 sentence-transformers 库加载
  model_name = "sentence-transformers/all-MiniLM-L6-v2"  # 轻量级，适合本地
  ```
- **维度**：384 或 768
- **论文**：[BERT: Pre-training of Deep Bidirectional Transformers for Language Understanding](https://arxiv.org/abs/1810.04805)
- **GitHub**：https://github.com/UKPLab/sentence-transformers

#### ✅ **OpenAI Embeddings (text-embedding-ada-002)**

- **特点**：
  - 商业 API，高精度，开箱即用
  - 维度：1536
  - 不适合本地部署，但可用于生产环境调用
- **适用场景**：快速原型、高精度需求、无需本地模型维护
- **API 示例（Golang）**：
  ```go
  // 使用 OpenAI Go SDK
  resp, err := client.CreateEmbeddings(ctx, openai.EmbeddingRequest{
      Input: []string{"Hello world"},
      Model: "text-embedding-ada-002",
  })
  if err != nil {
      log.Fatal(err)
  }
  vector := resp.Data[0].Embedding // []float32
  ```

### (2) 多模态嵌入模型

#### ✅ **CLIP (Contrastive Language–Image Pretraining)**

- **来源**：OpenAI
- **特点**：
  - 同时理解图像和文本
  - 可实现“图文互搜”：用文字搜图，或用图搜文字
  - 图像和文本被映射到**同一向量空间**
- **典型应用**：
  - 图像搜索引擎
  - 内容审核
  - 推荐系统
- **开源实现**：
  - Hugging Face 提供多个 CLIP 变体（如 `openai/clip-vit-base-patch32`）
  - 可在本地使用 `transformers` + `PIL` 加载图像并生成嵌入
- **论文**：[Learning Transferable Visual Models From Natural Language Supervision](https://arxiv.org/abs/2103.00020)

## 3. 距离度量的数学基础

向量数据库通过计算向量之间的“距离”来判断相似性。不同距离度量适用于不同场景。

### (1) 余弦相似度（Cosine Similarity）

- **定义**：两个向量夹角的余弦值
  $$
  \text{cos}(\mathbf{a}, \mathbf{b}) = \frac{\mathbf{a} \cdot \mathbf{b}}{\|\mathbf{a}\| \|\mathbf{b}\|}
  $$
- **取值范围**：`[-1, 1]`，值越大越相似
- **优点**：
  - 对向量长度不敏感，只关注方向
  - 适合文本语义相似度
- **与内积等价性**：
  - 若向量已**归一化（L2-normalized）**，则余弦相似度 = 内积
  - 即：
	  $$
	  (\|\mathbf{a}\| = \|\mathbf{b}\| = 1 \Rightarrow \mathbf{a} \cdot \mathbf{b} = \cos(\mathbf{a}, \mathbf{b}))
	$$
  - 因此许多数据库（如 Milvus）在归一化后使用内积作为相似度度量

### (2) L2 距离（欧氏距离，Euclidean Distance）

- **定义**：
  $$
  d(\mathbf{a}, \mathbf{b}) = \sqrt{\sum_{i=1}^n (a_i - b_i)^2}
  $$
- **特点**：
  - 衡量两点间的直线距离
  - 越小越相似
- **适用场景**：图像特征、聚类任务

### (3) 内积（Inner Product / Dot Product）

- **定义**：
  $$
  \mathbf{a} \cdot \mathbf{b} = \sum_{i=1}^n a_i b_i
  $$
- **特点**：
  - 未归一化时，受向量长度影响
  - 归一化后等价于余弦相似度
- **优势**：计算速度快，适合 GPU 加速

### ✅ 三者关系总结

| 度量 | 是否归一化 | 越大越相似？ | 典型用途 |
|------|------------|--------------|----------|
| 余弦相似度 | 否 | 是 | 语义搜索 |
| L2 距离 | 否 | 否（越小越好） | 图像检索 |
| 内积 | 是（必须归一化） | 是 | 高性能 ANN 搜索 |

> ⚠️ **重要提示**：在使用向量数据库时，务必确认 embedding 模型输出是否已归一化。若未归一化，使用内积可能导致错误结果。

## 4. 高维空间的“诅咒”与近似搜索的必要性

### (1) 什么是“维度灾难”（Curse of Dimensionality）？

随着维度增加，数据在高维空间中变得极度稀疏，导致：

- 所有点之间的距离趋于相近
- 精确搜索（暴力扫描）计算成本爆炸式增长
- 索引效率下降

> 📌 **举例**：在 768 维空间中，即使两个向量语义完全不同，它们的 L2 距离也可能很小，而相似的向量距离也可能很大——这使得精确搜索不可靠且低效。

### (2) 为什么需要近似最近邻（ANN）搜索？

- **精确搜索（Brute-force）**：计算查询向量与数据库中所有向量的距离，取 Top-K 最近的。时间复杂度 (O(N))，N 为向量总数。
- **ANN 搜索**：牺牲少量精度，换取巨大性能提升（(O(log N)) 或更低。

| 方法 | 精度 | 速度 | 内存 | 适用场景 |
|------|------|------|------|----------|
| 暴力搜索 | 100% | 极慢 | 高 | 小数据集（< 10K） |
| HNSW | 高 | 极快 | 高 | 通用，推荐 |
| IVF | 中高 | 快 | 中 | 大规模数据 |
| PQ | 中 | 极快 | 低 | 超大规模 |

### (3) ANN 的核心思想

- **索引预构建**：在数据插入时建立索引结构（如图、聚类、哈希）
- **搜索剪枝**：只访问最可能相关的子集，跳过无关区域
- **精度-速度权衡**：可通过参数（如 `ef_search`）调节搜索范围与精度

> 📚 **经典论文**：
> - [HNSW: Hierarchical Navigable Small World Graphs](https://arxiv.org/abs/1603.09320) —— 本文提出的 HNSW 是当前最高效的 ANN 算法之一
> - [Product Quantization for Nearest Neighbor Search](https://lear.inrialpes.fr/pubs/2011/JDS11/jegou_searching_with_quantizations.pdf) —— PQ 压缩技术奠基之作

## ✅ 实践示例：在 M1 Mac 上生成本地嵌入（Golang + Python）

由于主流 embedding 模型为 Python 生态，建议使用 Go 调用本地 Python 服务或直接集成。

### 方案一：本地运行 SBERT（Python + Go 调用）

#### 1. 安装依赖（M1 兼容）

```bash
# 使用 miniconda 创建 ARM64 环境
conda create -n embeddings python=3.10
conda activate embeddings
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cpu
pip install sentence-transformers
```

#### 2. 启动嵌入服务（`embed_server.py`）

```python
from sentence_transformers import SentenceTransformer
from flask import Flask, request, jsonify
import numpy as np

app = Flask(__name__)
model = SentenceTransformer('sentence-transformers/all-MiniLM-L6-v2')

@app.route('/embed', methods=['POST'])
def embed():
    texts = request.json.get('texts', [])
    vectors = model.encode(texts)
    # 转为 list of list[float]
    return jsonify(vectors=vectors.tolist())

if __name__ == '__main__':
    app.run(port=5000)
```

启动服务：
```bash
python embed_server.py
```

#### 3. Golang 调用示例（`main.go`）

```go
package main

import (
	"bytes"
	"encoding/json"
	"fmt"
	"io"
	"log"
	"net/http"
)

type EmbedRequest struct {
	Texts []string `json:"texts"`
}

type EmbedResponse struct {
	Vectors [][]float32 `json:"vectors"`
}

func getEmbeddings(texts []string) ([][]float32, error) {
	reqBody := EmbedRequest{Texts: texts}
	body, _ := json.Marshal(reqBody)

	resp, err := http.Post("http://localhost:5000/embed", "application/json", bytes.NewBuffer(body))
	if err != nil {
		return nil, err
	}
	defer resp.Body.Close()

	data, _ := io.ReadAll(resp.Body)
	var result EmbedResponse
	json.Unmarshal(data, &result)

	return result.Vectors, nil
}

func main() {
	vectors, err := getEmbeddings([]string{"Hello world", "Vector database is cool"})
	if err != nil {
		log.Fatal(err)
	}
	fmt.Printf("Generated %d vectors, dim: %d\n", len(vectors), len(vectors[0]))
}
```

运行：
```bash
go run main.go
# Output: Generated 2 vectors, dim: 384
```
