## 2. 连接池与客户端初始化（支持 gRPC/HTTP）

### (1) 创建可复用的 Qdrant 客户端

```go
// client.go
package main

import (
	"context"
	"fmt"
	"google.golang.org/grpc"
	"log"
	"time"

	qdrant "github.com/qdrant/go-client/qdrant"
)

type QdrantClient struct {
	client qdrant.Client
}

func NewQdrantClient(host string, port int) (*QdrantClient, error) {
	// 使用 gRPC 连接（性能更高）
	conn, err := grpc.Dial(
		fmt.Sprintf("%s:%d", host, port),
		grpc.WithInsecure(),
		grpc.WithTimeout(10*time.Second),
		grpc.WithBlock(), // 阻塞等待连接建立
	)
	if err != nil {
		return nil, fmt.Errorf("failed to connect to Qdrant: %w", err)
	}

	client := qdrant.NewClient(&qdrant.ClientConfig{
		Transport: &qdrant.GrpcTransport{
			Conn: conn,
		},
	})

	return &QdrantClient{client: client}, nil
}
```

> ✅ **生产设计要点**：
> - 使用 **gRPC** 而非 HTTP，降低延迟
> - `WithBlock()` 确保连接建立成功
> - 连接池由 gRPC 底层管理（自动复用）

## 3. 创建集合（Collection）与 Schema 设计

### (1) 定义集合 Schema

```go
// schema.go
func (qc *QdrantClient) CreateCollection(ctx context.Context) error {
	// 向量配置：768维，余弦相似度
	vectorParams := &qdrant.VectorParams{
		Size:     768,
		Distance: qdrant.Distance_Cosine,
	}

	// 标量字段（元数据）
	payloadSchema := map[string]*qdrant.PayloadSchemaInfo{
		"category": {DataType: qdrant.PayloadSchemaType_KEYWORD},
		"doc_id":   {DataType: qdrant.PayloadSchemaType_INTEGER},
		"created":  {DataType: qdrant.PayloadSchemaType_INTEGER},
	}

	// 创建集合请求
	req := &qdrant.CreateCollection{
		CollectionName: "documents",
		VectorsConfig: &qdrant.VectorsConfig{
			Config: &qdrant.VectorsConfig_Params{
				Params: vectorParams,
			},
		},
		PayloadSchema: payloadSchema,
	}

	// 执行创建
	_, err := qc.client.Collections().Create(ctx, req)
	if err != nil {
		return fmt.Errorf("failed to create collection: %w", err)
	}

	// 等待集合就绪
	return qc.waitForCollectionReady(ctx, "documents")
}

func (qc *QdrantClient) waitForCollectionReady(ctx context.Context, name string) error {
	ticker := time.NewTicker(500 * time.Millisecond)
	defer ticker.Stop()

	for {
		select {
		case <-ticker.C:
			resp, err := qc.client.Collections().Get(ctx, &qdrant.GetCollection{CollectionName: name})
			if err == nil && resp.Status == qdrant.CollectionStatus_CollectionStatusReady {
				log.Printf("Collection %s is ready\n", name)
				return nil
			}
		case <-ctx.Done():
			return ctx.Err()
		}
	}
}
```

> ✅ **Schema 设计建议**：
> - 向量维度与 embedding 模型一致（如 SBERT 为 384 或 768）
> - 元数据字段使用 `keyword`（字符串）、`integer`、`bool` 等类型，便于过滤

## 4. 批量插入（Upsert）与错误处理

### (1) 批量插入向量数据

```go
// upsert.go
type Document struct {
	ID       uint64
	Vector   []float32
	Category string
	DocID    int64
	Created  int64
}

func (qc *QdrantClient) BatchUpsert(ctx context.Context, docs []Document) error {
	points := make([]*qdrant.PointStruct, 0, len(docs))

	for _, doc := range docs {
		// 构建 payload（元数据）
		payload := map[string]qdrant.PayloadVariant{
			"category": qdrant.NewKeywordPayload(doc.Category),
			"doc_id":   qdrant.NewIntegerPayload(doc.DocID),
			"created":  qdrant.NewIntegerPayload(doc.Created),
		}

		point := &qdrant.PointStruct{
			Id:      qdrant.NewPointIdNum(doc.ID),
			Vector:  doc.Vector,
			Payload: payload,
		}
		points = append(points, point)
	}

	req := &qdrant.UpsertPoints{
		CollectionName: "documents",
		Points:         points,
	}

	// 执行批量插入
	_, err := qc.client.Points().Upsert(ctx, req)
	if err != nil {
		return fmt.Errorf("batch upsert failed: %w", err)
	}

	log.Printf("Inserted %d points\n", len(points))
	return nil
}
```

> ✅ **生产优化**：
> - 批量大小建议 100~1000 条（避免单次请求过大）
> - 使用 `Upsert` 支持更新操作

## 5. 元数据过滤 + 向量搜索（混合查询）

### (1) 构建过滤条件

```go
// filter.go
func buildFilter(category string, minCreated int64) *qdrant.Filter {
	return &qdrant.Filter{
		Should: nil,
		Must: []*qdrant.Conditions{
			{
				Condition: &qdrant.Conditions_Field{
					Field: &qdrant.FieldCondition{
						Key: "category",
						Range: nil,
						Match: &qdrant.Match{
							MatchValue: &qdrant.Match_Keyword{Keyword: category},
						},
					},
				},
			},
			{
				Condition: &qdrant.Conditions_Field{
					Field: &qdrant.FieldCondition{
						Key: "created",
						Range: &qdrant.Range{
							Gte: &qdrant.Variant{Variant: &qdrant.Variant_Integer{Integer: minCreated}},
						},
						Match: nil,
					},
				},
			},
		},
		MustNot: nil,
	}
}
```

---

### (2) 执行混合搜索（Hybrid Search）

```go
// search.go
func (qc *QdrantClient) SearchWithFilter(
	ctx context.Context,
	queryVector []float32,
	category string,
	minCreated int64,
	limit int,
) ([]*qdrant.ScoredPoint, error) {

	filter := buildFilter(category, minCreated)

	req := &qdrant.SearchPoints{
		CollectionName: "documents",
		Vector:         queryVector,
		Filter:         filter,
		Limit:          int64(limit),
		WithPayload:    &qdrant.WithPayloadSelector{SelectorOptions: &qdrant.WithPayloadSelector_Enable{Enable: true}},
		WithVectors:    false, // 不返回向量，减少网络开销
	}

	resp, err := qc.client.Points().Search(ctx, req)
	if err != nil {
		return nil, fmt.Errorf("search failed: %w", err)
	}

	return resp.Result, nil
}
```

> ✅ **关键设计**：
> - `WithPayload: true` 返回元数据
> - `WithVectors: false` 避免传输大向量
> - 过滤条件通过 `Must` 实现 AND 逻辑

## 6. 客户端底层机制解析

### (1) gRPC 流式与连接复用

- gRPC 使用 **HTTP/2 多路复用**，单连接可并发多个请求
- `grpc.ClientConn` 内部维护连接池，无需手动管理
- 支持 **Keepalive** 检测连接健康

## 7. 完整主函数示例

```go
// main.go
func main() {
	ctx := context.Background()

	// 初始化客户端
	client, err := NewQdrantClient("localhost", 6334) // gRPC 端口
	if err != nil {
		log.Fatal(err)
	}

	// 创建集合
	if err := client.CreateCollection(ctx); err != nil {
		log.Fatal(err)
	}

	// 生成测试数据（模拟 embedding）
	docs := []Document{
		{ID: 1, Vector: randomVector(768), Category: "tech", DocID: 1001, Created: 1700000000},
		{ID: 2, Vector: randomVector(768), Category: "finance", DocID: 1002, Created: 1700000100},
	}

	// 批量插入
	if err := client.BatchUpsert(ctx, docs); err != nil {
		log.Fatal(err)
	}

	// 混合搜索
	results, err := client.SearchWithFilter(ctx, docs[0].Vector, "tech", 1699999999, 5)
	if err != nil {
		log.Fatal(err)
	}

	for _, r := range results {
		fmt.Printf("ID: %d, Score: %.4f, Category: %s\n",
			r.Id.GetNum(), r.Score, r.Payload["category"].GetKeyword())
	}
}

func randomVector(dim int) []float32 {
	vec := make([]float32, dim)
	for i := range vec {
		vec[i] = rand.Float32()*2 - 1 // [-1, 1]
	}
	return vec
}
```
