## 1. 评估指标体系

### 1.1 分类任务评估指标

#### 1.1.1 基础指标

**混淆矩阵(Confusion Matrix)**：

$$\begin{pmatrix}
\text{TN} & \text{FP} \\
\text{FN} & \text{TP}
\end{pmatrix}$$

其中：
- TP (True Positive)：正确预测为正类
- TN (True Negative)：正确预测为负类
- FP (False Positive)：错误预测为正类
- FN (False Negative)：错误预测为负类

**核心指标计算**：

$$\begin{align}
\text{Accuracy} &= \frac{\text{TP} + \text{TN}}{\text{TP} + \text{TN} + \text{FP} + \text{FN}} \\
\text{Precision} &= \frac{\text{TP}}{\text{TP} + \text{FP}} \\
\text{Recall} &= \frac{\text{TP}}{\text{TP} + \text{FN}} \\
\text{F1-Score} &= \frac{2 \times \text{Precision} \times \text{Recall}}{\text{Precision} + \text{Recall}}
\end{align}$$

#### 1.1.2 高级指标

**F-beta分数**：

$$F_\beta = (1 + \beta^2) \cdot \frac{\text{Precision} \times \text{Recall}}{\beta^2 \cdot \text{Precision} + \text{Recall}}$$

其中：
- $\beta > 1$：更重视召回率
- $\beta < 1$：更重视精确率
- $\beta = 1$：F1分数

**Matthews相关系数(MCC)**：

$$\text{MCC} = \frac{\text{TP} \times \text{TN} - \text{FP} \times \text{FN}}{\sqrt{(\text{TP} + \text{FP})(\text{TP} + \text{FN})(\text{TN} + \text{FP})(\text{TN} + \text{FN})}}$$

MCC范围为[-1, 1]，是处理不平衡数据的理想指标。

**ROC-AUC与PR-AUC**：

```python
from sklearn.metrics import roc_auc_score, average_precision_score
import numpy as np

def comprehensive_evaluation(y_true, y_pred, y_prob):
    """综合评估函数"""
    metrics = {}
    
    # 基础指标
    metrics['accuracy'] = accuracy_score(y_true, y_pred)
    metrics['precision'] = precision_score(y_true, y_pred, average='weighted')
    metrics['recall'] = recall_score(y_true, y_pred, average='weighted')
    metrics['f1'] = f1_score(y_true, y_pred, average='weighted')
    
    # 高级指标
    metrics['mcc'] = matthews_corrcoef(y_true, y_pred)
    metrics['roc_auc'] = roc_auc_score(y_true, y_prob)
    metrics['pr_auc'] = average_precision_score(y_true, y_prob)
    
    return metrics
```

#### 1.1.3 多类别评估

**宏平均(Macro Average)**：

$$\text{Macro-F1} = \frac{1}{C} \sum_{i=1}^{C} F1_i$$

**微平均(Micro Average)**：

$$\text{Micro-F1} = \frac{2 \times \text{Micro-Precision} \times \text{Micro-Recall}}{\text{Micro-Precision} + \text{Micro-Recall}}$$

其中：
$$\text{Micro-Precision} = \frac{\sum_{i=1}^{C} \text{TP}_i}{\sum_{i=1}^{C} (\text{TP}_i + \text{FP}_i)}$$

**加权平均(Weighted Average)**：

$$\text{Weighted-F1} = \sum_{i=1}^{C} w_i \times F1_i$$

其中$w_i = \frac{n_i}{n}$是类别$i$的样本比例。

### 1.2 语言模型评估指标

#### 1.2.1 困惑度(Perplexity)

**定义与计算**：

困惑度是评估语言模型性能的核心指标，衡量模型对未知文本的预测能力：

$\text{PPL} = \exp\left(-\frac{1}{T} \sum_{i=1}^{T} \log P(w_i | w_1, ..., w_{i-1})\right)$

其中：
- $T$ 是测试集的总词数(tokens)
- $P(w_i | w_1, ..., w_{i-1})$ 是模型预测当前词的概率

**直观理解**：
- PPL = 1：模型完美预测
- PPL = V（词汇表大小）：等效于随机猜测
- 实际值：优秀模型的PPL通常在20-100之间

**计算示例**：

```python
import torch
import torch.nn.functional as F

def calculate_perplexity(model, data_loader, device):
    """计算困惑度"""
    model.eval()
    total_loss = 0
    total_tokens = 0
    
    with torch.no_grad():
        for batch in data_loader:
            input_ids = batch['input_ids'].to(device)
            labels = batch['labels'].to(device)
            
            outputs = model(input_ids, labels=labels)
            loss = outputs.loss
            
            # 累积损失和token数
            total_loss += loss.item() * input_ids.size(1)
            total_tokens += input_ids.size(1)
    
    # 计算困惑度
    avg_loss = total_loss / total_tokens
    perplexity = torch.exp(torch.tensor(avg_loss))
    
    return perplexity.item()
```

#### 1.2.2 BLEU分数

**定义**：

BLEU (Bilingual Evaluation Understudy) 用于评估机器翻译和文本生成质量：

$$\text{BLEU} = \text{BP} \times \exp\left(\sum_{n=1}^{N} w_n \log p_n\right)$$

其中：
- $p_n$ 是n-gram精确率
- $w_n$ 是权重（通常均匀分布）
- BP是简洁性惩罚因子

**简洁性惩罚**：

$$\text{BP} = \begin{cases}
1 & \text{if } c > r \\
\exp(1 - r/c) & \text{if } c \leq r
\end{cases}$$

其中$c$是候选译文长度，$r$是参考译文长度。

#### 1.2.3 ROUGE分数

**ROUGE-N**：

$$\text{ROUGE-N} = \frac{\sum_{S \in \text{RefSummaries}} \sum_{\text{gram}_n \in S} \text{Count}_{\text{match}}(\text{gram}_n)}{\sum_{S \in \text{RefSummaries}} \sum_{\text{gram}_n \in S} \text{Count}(\text{gram}_n)}$$

**ROUGE-L**（最长公共子序列）：

$$\text{ROUGE-L} = \frac{(1 + \beta^2) R_{\text{lcs}} P_{\text{lcs}}}{\beta^2 R_{\text{lcs}} + P_{\text{lcs}}}$$

### 1.3 文本相似度计算与评估

本节详细介绍从传统统计到深度学习的各种文本相似度计算方法。

#### 1.3.1 基于词汇的相似度 (Lexical Similarity)

这类方法直接比较文本表面的词汇重叠情况，计算速度快，但无法捕捉深层语义。

**TF-IDF & 余弦相似度**:
- **原理**: 使用TF-IDF加权词向量，通过余弦相似度衡量向量空间中的夹角。
- **公式**: `sim(A,B) = cos(θ) = (A·B) / (||A|| ||B||)`
- **适用场景**: 文档检索、关键词匹配。

**Jaccard相似度**:
- **原理**: 计算两个文本词集合的交集与并集之比。
- **公式**: `J(A,B) = |A ∩ B| / |A ∪ B|`
- **适用场景**: 短文本、集合相似性度量。

**编辑距离 (Levenshtein Distance)**:
- **原理**: 计算从一个字符串转换到另一个所需的最少单字符编辑（插入、删除、替换）次数。
- **适用场景**: 拼写纠错、DNA序列比对。

**最长公共子序列 (LCS)**:
- **原理**: 找到两个序列共有的、最长的子序列的长度。
- **适用场景**: 文本抄袭检测、版本控制。

#### 1.3.2 基于静态词嵌入的相似度 (Static Embedding Similarity)

通过预训练的词向量（如Word2Vec, GloVe）来捕捉词语的语义。

**词向量平均法**:
- **原理**: 将句子中所有词的词向量相加并取平均，得到句子向量，再计算句子向量间的余弦相似度。
- **局限**: 丢失了词序信息，且常用词可能会主导句子向量。

**Doc2Vec**:
- **原理**: Word2Vec的扩展，直接学习整个文档的向量表示，考虑了词序信息。
- **适用场景**: 文档/段落级别的相似度计算。

#### 1.3.3 基于上下文嵌入的相似度 (Contextual Embedding Similarity)

使用Transformer等深度学习模型生成上下文相关的词或句子嵌入，能够理解一词多义。

**BERT**:
- **原理**: 使用预训练的BERT模型获取整个句子的`[CLS]` token表示，或对所有token的输出向量进行平均池化(mean pooling)，得到句子嵌入。
- **优势**: 强大的上下文理解能力。

**Sentence-BERT (S-BERT)**:
- **原理**: 对BERT进行微调，专门用于生成语义上有意义的句子嵌入。使用孪生网络(Siamese Network)结构训练，使得语义相似的句子在向量空间中距离更近。
- **优势**: 在语义相似度任务上通常优于标准BERT，且推理速度快。
- **实现**:
```python
from sentence_transformers import SentenceTransformer, util
import torch

# 加载预训练模型
model = SentenceTransformer('paraphrase-multilingual-MiniLM-L12-v2')

# 待比较的句子
sentences1 = ['这是一个测试句子', '深度学习模型评估']
sentences2 = ['这是一个测试用的句子', '如何评估深度学习模型？']

# 编码为向量
embeddings1 = model.encode(sentences1, convert_to_tensor=True)
embeddings2 = model.encode(sentences2, convert_to_tensor=True)

# 计算余弦相似度
cosine_scores = util.pytorch_cos_sim(embeddings1, embeddings2)

print(f"句子1: {sentences1[0]}")
print(f"句子2: {sentences2[0]}")
print(f"相似度: {cosine_scores[0][0]:.4f}\n")

print(f"句子1: {sentences1[1]}")
print(f"句子2: {sentences2[1]}")
print(f"相似度: {cosine_scores[1][1]:.4f}")
```

## 7. 模型伦理与公平性

评估模型不仅要关注其性能指标，还必须考虑其社会影响，特别是偏见、公平性和隐私问题。

### 7.1 偏见检测与治理

**偏见(Bias)**: 指模型由于训练数据或算法设计中的缺陷，对特定群体产生系统性的、不公平的预测结果。常见的偏见包括性别、种族、地域偏见等。

**评估指标**:
- **人口均等(Demographic Parity)**: 模型预测结果中，不同受保护群体（如男性、女性）被划分为正类的比例应该相等。`P(ŷ=1|A=a) = P(ŷ=1|A=b)`
- **机会均等(Equalized Odds)**: 在真实标签为正的情况下，不同群体被正确预测为正类的比例应该相等。`P(ŷ=1|Y=1, A=a) = P(ŷ=1|Y=1, A=b)`

**治理方法**:
- **预处理**: 对训练数据进行重采样或重加权，以平衡不同群体的分布。
- **在处理(In-processing)**: 在模型训练过程中加入公平性约束，如对抗性去偏。
- **后处理**: 调整模型的预测阈值，以满足公平性指标。

### 7.2 隐私保护技术

**隐私风险**: 大模型可能在训练过程中“记住”敏感信息（如个人身份信息、医疗记录），并在生成时泄露。

**评估与解决方案**:
- **成员推断攻击(Membership Inference Attack)**: 用于评估模型是否记住了特定的训练样本。
- **差分隐私(Differential Privacy, DP)**: 在训练过程中向梯度或数据注入噪声，为个体数据提供可证明的隐私保障。
- **联邦学习(Federated Learning)**: 在不将原始数据移出本地设备的情况下进行模型训练，从源头上保护数据隐私。

### 7.3 可解释性评估

**可解释性(Explainable AI, XAI)**: 指人类能够理解模型决策过程的能力。

**评估方法**:
- **局部可解释性**: 解释单个预测结果。
  - **LIME (Local Interpretable Model-agnostic Explanations)**: 通过在预测点周围扰动输入，用一个简单的、可解释的模型（如线性模型）来近似局部决策边界。
  - **SHAP (SHapley Additive exPlanations)**: 应用博弈论中的Shapley值，将每个特征对最终预测的贡献进行量化。
- **全局可解释性**: 理解模型的整体行为。

## 8. 评估最佳实践

### 8.1 评估流程设计

一个稳健的评估流程是确保模型质量和可靠性的基石。

1.  **明确业务目标**: 将业务问题转化为可量化的模型评估指标。
2.  **创建黄金测试集**: 从数据中划分出一个独立的、高质量的测试集，此后不再触碰，直到最终评估阶段。
3.  **交叉验证**: 使用训练集和验证集进行模型选择和超参数调优。
4.  **错误分析**: 在验证集上进行深入的错误分析，指导模型迭代。
5.  **最终评估**: 在所有开发和调优完成后，使用黄金测试集进行一次性评估，作为模型的最终性能报告。
6.  **部署后监控**: 模型上线后，持续监控其性能，警惕数据漂移和概念漂移。

### 8.2 基准测试 (Benchmarking)

- **建立基线**: 任何复杂的模型都应与一个简单的基线模型（如TF-IDF+逻辑回归）进行比较，以证明其复杂性的必要性。
- **使用公共基准**: 在学术界或行业标准数据集（如GLUE, SuperGLUE, MMLU）上进行测试，可以客观地衡量模型在通用能力上的表现。

### 8.3 持续监控

**数据漂移(Data Drift)**: 生产环境中的数据分布随时间变化，与训练数据分布不再一致。
- **检测**: 使用统计检验（如KS检验）比较训练集和生产数据的特征分布。

**概念漂移(Concept Drift)**: 特征与目标变量之间的关系发生变化。
- **检测**: 监控模型在带有新标签的生产数据上的性能下降情况。

**MLOps实践**: 建立自动化的MLOps流水线，当检测到性能下降或数据漂移时，自动触发模型重新训练、评估和部署流程。
