## 10.1 beanstalk的搭建

环境 ubuntu18.04

```bash

## 一，因为本地和docker里使用的是同一个镜像，所以可以在本地先把beanstalkd编译好

```

```shell
cd ~/docker
git clone https://github.com/beanstalkd/beanstalkd.git
cd  ~/docker/beanstalkd
# 然后执行
make
```

二，写Dockerfile

```dockerfile
FROM daocloud.io/ubuntu:18.04
RUN adduser beanstalkd
RUN mkdir /data && chown beanstalkd:beanstalkd /data
VOLUME /data
WORKDIR /data
COPY docker-entrypoint.sh /usr/local/bin/
COPY beanstalkd /usr/local/bin/
ENV PATH ${PATH}:/usr/local/bin/
USER beanstalkd
ENTRYPOINT ["docker-entrypoint.sh"]
EXPOSE 11300
CMD ["beanstalkd"]
```

```bash
二，写docker-entrypoint.sh文件
```

```shell
#!/bin/sh
set -e
# first arg is `-f` or `--some-option`
# or first arg is `something.conf`
if [ "${1#-}" != "$1" ] || [ "${1%.conf}" != "$1" ]; then
set -- beanstalkd "$@"
fi
# allow the container to be started with `--user`
if [ "$1" = 'beanstalkd' -a "$(id -u)" = '0' ]; then
find . \! -user beanstalkd -exec chown beanstalkd '{}' +
exec su beanstalkd "$0" "$@"
fi
exec "$@"
```

## 几个注意点。

```bash
一， COPY docker-entrypoint.sh /usr/local/bin/ 这个命令中第一个文件是宿主机文件，这里直接写文件名的原因是该文件和Dockerfile文件在一个文件夹下，如果不在一个文件夹下就要写绝对路径
```

```bash
二，ENTRYPOINT 一般是写一个 .sh 的文件，因为ENTRYPOINT执行后，后面就不再解析参数，也就是不能解析docker执行所加的命令行参数，所以要使用一个 .sh文件。
```

## 然后就可以启动容器

```shell
sudo docker run -d --name beanstalk --restart=always -v /data/beanstalk/data:/data -p 11300:11300 beanstalkd:v1
```

也可以把git clone这一步放在Dockerfile去执行

```dockerfile
FROM daocloud.io/ubuntu:18.04 as builder
# 更改源
RUN sed -i "s/archive.ubuntu.com/mirrors.aliyun.com/g" /etc/apt/sources.list

# 不能加sudo,一定要加 -y
RUN apt update && apt -y install gcc make git
WORKDIR /data
RUN git clone https://github.com/beanstalkd/beanstalkd.git
WORKDIR /data/beanstalkd
RUN make && ls -la

FROM daocloud.io/ubuntu:18.04
RUN adduser beanstalkd
RUN mkdir /data && chown beanstalkd:beanstalkd /data
VOLUME /data
WORKDIR /data
COPY docker-entrypoint.sh /usr/local/bin/
COPY --from=builder /data/beanstalkd/beanstalkd /usr/local/bin/
ENV PATH ${PATH}:/usr/local/bin/
USER beanstalkd
ENTRYPOINT ["docker-entrypoint.sh"]
EXPOSE 11300
CMD ["beanstalkd"]
```
