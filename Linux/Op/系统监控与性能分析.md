## 1. iostat —— 磁盘 I/O 与 CPU 监控

### 1.1 简介

`iostat` 用于监视系统的磁盘 I/O 活动，同时也会报告 CPU 使用情况。它的缺点是只能分析系统整体，不能针对单个进程深入分析。

### 1.2 基本用法

```bash
iostat [选项] [刷新间隔(秒)] [刷新次数]
```

### 1.3 常用选项

| 选项 | 说明 |
|------|------|
| `-c` | 显示 CPU 使用情况 |
| `-d` | 显示磁盘使用情况 |
| `-k` | 以 KB 为单位显示 |
| `-m` | 以 MB 为单位显示 |
| `-N` | 显示 LVM（磁盘阵列）信息 |
| `-n` | 显示 NFS 使用情况 |
| `-p` | 显示每块磁盘每个分区的使用情况 |
| `-t` | 显示终端和 CPU 信息 |
| `-x` | 显示扩展统计（详细 I/O 指标） |

### 1.4 常用命令示例

```bash
# 每秒刷新一次，显示详细 I/O 指标
iostat -x -d 1

# 每 2 秒刷新一次，共显示 3 次
iostat 2 3
```

### 1.5 CPU 指标（`-c` 输出）

| 指标 | 说明 |
|------|------|
| `%user` | CPU 在用户模式下花费的时间百分比 |
| `%nice` | CPU 在带 nice 值的用户模式下花费的时间百分比 |
| `%system` | CPU 在系统模式下花费的时间百分比 |
| `%iowait` | CPU 等待 I/O 完成的时间百分比 |
| `%steal` | 虚拟机被 hypervisor 窃取的 CPU 时间百分比 |
| `%idle` | CPU 空闲时间百分比 |

### 1.6 磁盘 I/O 指标（`-x` 输出）

> `iostat` 的重点是磁盘性能，而非 CPU。

| 指标 | 说明 |
|------|------|
| `Device` | 设备名称 |
| `rrqm/s` | 每秒合并的读请求数 |
| `wrqm/s` | 每秒合并的写请求数 |
| `r/s` | 每秒读操作数 |
| `w/s` | 每秒写操作数 |
| `rkB/s` | 每秒读取的 KB 数 |
| `wkB/s` | 每秒写入的 KB 数 |
| `avgrq-sz` | 平均每次 I/O 操作的数据大小（扇区） |
| `avgqu-sz` | 平均 I/O 队列长度 |
| `await` | 平均每次 I/O 操作的等待时间（ms），含队列等待 |
| `r_await` | 平均每次读操作的等待时间（ms） |
| `w_await` | 平均每次写操作的等待时间（ms） |
| `svctm` | 平均每次 I/O 操作的服务时间（ms）—— **该指标不可信，新版 sysstat 已移除** |
| `%util` | 设备用于 I/O 操作的时间百分比 |

### 1.7 重点关注指标

- **`%iowait`**：偏高说明磁盘存在 I/O 瓶颈。
- **`await`**：理想值 < 5 ms，> 10 ms 说明 I/O 响应偏慢。
- **`avgqu-sz`**：单块磁盘持续超过 2 时通常存在 I/O 瓶颈。如果是 RAID / LVM 逻辑卷，需将队列长度除以实际物理磁盘数量来评估单盘情况。
- **`%util`**：持续接近 100% 表示设备接近满负荷。

### 1.8 结合业务分析

| 业务类型 | 典型场景 | 关键指标 |
|----------|----------|----------|
| 随机读写频繁 | 图片存取、数据库、邮件服务器 | TPS（每秒事务数） |
| 顺序读写频繁 | 视频点播、文件同步 | 吞吐量（MB/s） |

## 2. lsof —— 查看进程打开的文件

### 2.1 简介

`lsof`（List Open Files）用于查看系统中被进程打开的文件、网络连接等。

### 2.2 常用命令

```bash
# 查看打开指定文件的进程
lsof /path/to/file

# 列出所有网络连接
lsof -i

# 列出所有 TCP 连接
lsof -i tcp

# 列出所有 UDP 连接
lsof -i udp

# 列出 80 端口上所有连接
lsof -i :80

# 列出 80 端口上所有 TCP 连接
lsof -i tcp:80

# 列出 25 端口上所有 UDP 连接
lsof -i udp:25

# 列出以 ngin 开头的进程打开的文件
lsof -c ngin

# 列出 PID 为 20711 的进程打开的文件
lsof -p 20711

# 列出指定用户打开的文件
lsof -u uasp

# 将 TCP 连接和指定用户文件信息合并输出（OR 关系）
lsof -u uasp -i tcp

# 指定用户 AND TCP 连接同时满足（AND 关系）
lsof -a -u uasp -i tcp

# 列出目录下被进程打开的文件（不递归）
lsof +d /usr/local/

# 递归列出目录下被进程打开的文件
lsof +D /usr/local/

# 每隔 3 秒轮询一次指定主机的指定端口连接
lsof -i @peida.linux:20,21,22,25,53,80 -r 3
```

### 2.3 常用选项速查

| 选项 | 说明 |
|------|------|
| `-a` | AND 逻辑，合并多个条件 |
| `-c <name>` | 列出名称以指定字符串开头的进程打开的文件 |
| `-d <fd>` | 列出打开指定文件描述符的进程 |
| `+d <dir>` | 列出目录下被打开的文件（不递归） |
| `+D <dir>` | 递归列出目录下被打开的文件 |
| `-n` | 列出使用 NFS 的文件 |
| `-u <user>` | 列出指定用户打开的文件 |
| `-p <pid>` | 列出指定进程号打开的文件 |
| `-i [proto][@host][:port]` | 列出网络连接 |
| `-r <sec>` | 每隔指定秒数重复执行 |

## 3. top / htop / iotop —— 实时进程监控

### 3.1 top

`top` 是 Linux 下最常用的实时进程监控工具，显示 CPU、内存、进程等整体状态。

#### 输出字段说明

| 字段 | 说明 |
|------|------|
| `PID` | 进程 ID |
| `USER` | 进程所有者 |
| `PR` | 进程优先级（越小越优先） |
| `NI` | nice 值 |
| `VIRT` | 进程占用的虚拟内存 |
| `RES` | 进程占用的物理内存（常驻内存） |
| `SHR` | 进程使用的共享内存 |
| `S` | 进程状态：`S`=休眠，`R`=运行，`Z`=僵尸，`N`=nice 值为负 |
| `%CPU` | 进程的 CPU 使用率 |
| `%MEM` | 进程物理内存占总内存的百分比 |
| `TIME+` | 进程启动后累计使用的 CPU 时间 |
| `COMMAND` | 进程启动命令名 |

#### 常用交互键

| 按键 | 说明 |
|------|------|
| `<空格>` | 立即刷新 |
| `P` | 按 CPU 使用率排序 |
| `M` | 按内存使用量排序 |
| `T` | 按运行时间排序 |
| `m` | 切换内存信息显示 |
| `t` | 切换进程 / CPU 状态显示 |
| `c` | 切换命令名 / 完整命令行显示 |
| `q` | 退出 |
| `W` | 将当前配置写入 `~/.toprc` |

---

### 3.2 htop

`htop` 是 `top` 的增强版，需要单独安装：

```bash
sudo apt-get install htop    # Debian / Ubuntu
sudo yum install htop        # RHEL / CentOS
```

`htop` 的指标含义与 `top` 相同，但提供：
- 彩色、交互式界面
- 鼠标点击排序
- 更直观的进程树视图

> 不需要深入研究 htop 的高级功能 —— 使用较麻烦，可用其他命令替代。

---

### 3.3 iotop

`iotop` 用于按 I/O 大小对进程排序，定位 I/O 瓶颈进程。

```bash
# 安装
sudo apt-get install iotop
```

#### 常用用法

```bash
# 只显示正在产生 I/O 的进程
iotop -o

# 按 I/O 排序显示正在产生 I/O 的进程
iotop -op
```

#### 交互快捷键

| 按键 | 说明 |
|------|------|
| `o` | 切换 `--only`，只显示正在产生 I/O 的进程 |
| `r` | 反向排序 |
| `p` | 切换至 `--processes` 视图 |
| `a` | 切换至 `--accumulated`（累计 I/O） |
| `i` | 改变线程优先级 |
| `q` | 退出 |

## 4. vmstat / pidstat / dstat / mpstat

### 4.1 vmstat —— 虚拟内存统计

`vmstat`（Virtual Memory Statistics）对系统的虚拟内存、进程、CPU 活动进行整体监控，开销极低，适合在高负载服务器上使用。不足之处是无法深入分析单个进程。

#### 基本用法

```bash
vmstat [选项] [刷新间隔(秒)] [刷新次数]

# 最常用：每 3 秒刷新，共 3 次
vmstat 3 3
```

#### 常用选项

| 选项 | 说明 |
|------|------|
| `-a` | 显示活跃和非活跃内存 |
| `-f` | 显示系统启动以来的 fork 数量 |
| `-m` | 显示 slabinfo |
| `-n` | 只在开头显示一次字段名 |
| `-s` | 显示内存统计及各类系统活动计数 |
| `-d` | 显示磁盘统计 |
| `-p <分区>` | 显示指定磁盘分区统计 |
| `-S <单位>` | 指定单位：`k`(1000)，`K`(1024)，`m`(1000000)，`M`(1048576) |

#### 输出字段详解

**1. procs（进程）**

| 字段 | 说明 |
|------|------|
| `r` | 运行队列中的线程数（可运行但 CPU 尚未执行）。超过 CPU 核数时说明 CPU 存在瓶颈。通常单核不宜超过 2，整体不宜超过核数 × 2 |
| `b` | 等待 I/O 的进程数。持续偏高说明 I/O 繁忙 |

**2. memory（内存）**

| 字段 | 说明 |
|------|------|
| `swpd` | 已使用的虚拟内存。若 `swpd` ≠ 0 但 `si`/`so` 长期为 0，不影响性能 |
| `free` | 空闲物理内存 |
| `buff` | 用作缓冲的内存 |
| `cache` | 用作缓存的内存。cache 较大时，若频繁访问的文件都被缓存命中，磁盘读 IO（bi）会很 |

**3. swap（交换空间，KB）**

| 字段 | 说明 |
|------|------|
| `si` | 每秒从交换区读入内存的量 |
| `so` | 每秒写入交换区的量 |

> `free` 很少 ≠ 内存不够。若 `free` 少但 `si`/`so` 也一直很少（大多为 0），说明内存实际够用，性能不受影响。只有当 `si`/`so` 长期 > 0 时才需要关注。

**4. io（块/秒）**

| 字段 | 说明 |
|------|------|
| `bi` | 每秒从块设备读取的块数 |
| `bo` | 每秒写入块设备的块数 |

> 随机磁盘读写时，`bi`/`bo` 越大，CPU 的 I/O 等待（`wa`）也会越大。

**5. system（系统）**

| 字段 | 说明 |
|------|------|
| `in` | 每秒中断数（含时钟中断） |
| `cs` | 每秒上下文切换数 |

> 这两个值越大，内核消耗的 CPU 时间越大。

**6. cpu（百分比）**

| 字段 | 说明 |
|------|------|
| `us` | 用户进程执行时间 |
| `sy` | 系统进程执行时间。`us + sy > 80` 说明 CPU 不足 |
| `id` | 空闲时间（含 I/O 等待） |
| `wa` | 等待 I/O 时间。偏高说明 I/O 等待严重，可能因磁盘随机访问或磁盘瓶颈 |

### 4.2 pidstat —— 进程级资源统计

`pidstat` 是 sysstat 套件中的工具，用于监控全部或指定进程的 CPU、内存、线程、设备 I/O 等资源占用情况。首次运行显示自系统启动以来的统计值，之后显示自上次运行以来的增量。

#### 安装

```bash
sudo apt-get install sysstat    # Debian / Ubuntu
sudo yum install sysstat        # RHEL / CentOS
```

#### 常用选项

| 选项 | 说明 |
|------|------|
| `-u` | （默认）显示各进程的 CPU 使用统计 |
| `-r` | 显示各进程的内存使用统计 |
| `-d` | 显示各进程的 I/O 使用情况 |
| `-w` | 显示各进程的上下文切换情况 |
| `-t` | 显示线程级别的统计信息 |
| `-p <PID>` | 指定进程号 |
| `-T {TASK\|CHILD\|ALL}` | 监控级别：`TASK`=独立任务，`CHILD`=进程下所有线程，`ALL`=两者都报告 |
| `-I` | 在 SMP 环境下，报告任务的 CPU 使用率 / 核数 |
| `-l` | 显示命令名和全部参数 |
| `-h` | 单行输出所有活动，便于程序解析 |

#### 示例

```bash
# 查看所有进程的 CPU 使用情况（与 pidstat -u -p ALL 等效）
pidstat 3 1

# 查看内存使用统计
pidstat -r

# 查看 I/O 使用情况
pidstat -d

# 查看上下文切换，每 3 秒刷新 1 次
pidstat -w 3 1

# 显示线程级别统计
pidstat -t 3 1
```

#### 各模式输出字段

**CPU 模式（`-u`）：**

| 字段 | 说明 |
|------|------|
| `PID` | 进程 ID |
| `%usr` | 进程在用户空间占用的 CPU 百分比 |
| `%system` | 进程在内核空间占用的 CPU 百分比 |
| `%guest` | 进程在虚拟机占用的 CPU 百分比 |
| `%CPU` | 进程总 CPU 占用百分比 |
| `CPU` | 处理该进程的 CPU 编号 |
| `Command` | 进程对应的命令 |

**内存模式（`-r`）：**

| 字段 | 说明 |
|------|------|
| `PID` | 进程 ID |
| `Minflt/s` | 每秒次要缺页（不需从磁盘加载） |
| `Majflt/s` | 每秒主要缺页（需从磁盘加载） |
| `VSZ` | 虚拟地址空间大小（KB） |
| `RSS` | 常驻内存大小（KB） |
| `Command` | 命令名 |

**I/O 模式（`-d`）：**

| 字段 | 说明 |
|------|------|
| `PID` | 进程 ID |
| `kB_rd/s` | 每秒从磁盘读取的 KB |
| `kB_wr/s` | 每秒写入磁盘的 KB |
| `kB_ccwr/s` | 每秒被取消的写入 KB（截断脏 pagecache 时发生） |
| `COMMAND` | 命令名 |

**上下文切换模式（`-w`）：**

| 字段 | 说明 |
|------|------|
| `PID` | 进程 ID |
| `Cswch/s` | 每秒主动上下文切换数 |
| `Nvcswch/s` | 每秒被动上下文切换数 |
| `Command` | 命令名 |

**线程模式（`-t`）：**

| 字段 | 说明 |
|------|------|
| `TGID` | 主线程 ID |
| `TID` | 线程 ID |
| `%usr` / `%system` / `%guest` / `%CPU` / `CPU` / `Command` | 与 CPU 模式相同 |

### 4.3 dstat —— 全能系统统计工具

`dstat` 可替代 `vmstat`、`iostat`、`netstat`、`nfsstat`、`ifstat`，提供彩色界面和即时刷新。

#### 安装

```bash
sudo yum install -y dstat      # RHEL / CentOS
sudo apt-get install dstat     # Debian / Ubuntu
```

#### 基本用法

```bash
dstat [选项] [刷新间隔] [刷新次数]

# 每 5 秒刷新，默认显示 cpu/disk/net/page/system
dstat 5

# 每 5 秒刷新，共显示 10 次
dstat 5 10
```

> 默认等效于 `dstat -cdngy`，分别显示：cpu、disk、net、page、system，每秒刷新一次。

#### 常用选项

| 选项 | 说明 |
|------|------|
| `-c` | CPU：用户、系统、空闲、等待、硬中断、软中断 |
| `-C 0,1` | 指定显示 CPU0 和 CPU1 |
| `-d` | 磁盘读写数据量 |
| `-D hda,total` | 指定磁盘 |
| `-n` | 网络状态 |
| `-N eth1,total` | 指定网卡 |
| `-l` | 系统负载 |
| `-m` | 内存使用 |
| `-g` | 页面（分页）使用 |
| `-p` | 进程状态 |
| `-s` | 交换分区使用 |
| `-r` | I/O 请求情况 |
| `-y` | 系统状态 |
| `--ipc` | IPC 消息队列、信号量等 |
| `--socket` | TCP/UDP 端口状态 |
| `-a` | 默认选项，等同于 `-cdngy` |
| `-v` | 等同于 `-pmgdsc -D total` |
| `--output <文件>` | 以 CSV 格式输出到文件 |

#### 常用场景示例

```bash
# 后台运行，结果输出到 CSV 文件
dstat --output /root/dstat.csv &

# 监控 socket 状态
dstat --socket

# 显示最消耗 CPU 的进程
dstat --top-cpu

# 显示最消耗 CPU 时间的进程（ms）
dstat --top-cputime

# 显示消耗 I/O 最多的进程
dstat --top-io

# 显示延迟最大的进程
dstat --top-latency

# 显示用内存最多的进程
dstat --top-mem

# 同时显示 top-cpu 和 top-mem
dstat --top-mem --top-cpu

# 监控文件系统（文件数、inode 数）
dstat --fs
```

---

### 4.4 mpstat —— 多核 CPU 统计

`mpstat`（Multiprocessor Statistics）报告各 CPU 核心的统计信息。

#### 常用用法

```bash
# 查看所有 CPU 核心的统计，每 3 秒刷新，共 3 次
mpstat -P ALL 3 3
```

> 输出与 `vmstat` 的 CPU 部分类似，但按核心拆分。日常使用频率较低。

## 工具速查矩阵

| 工具 | 监控维度 | 粒度 | 适合场景 |
|------|----------|------|----------|
| `iostat` | 磁盘 I/O + CPU | 系统级 | 排查磁盘瓶颈 |
| `lsof` | 文件 / 网络连接 | 进程级 | 排查端口占用、文件句柄泄漏 |
| `top` | CPU / 内存 / 进程 | 系统级 + 进程级 | 日常监控首选 |
| `htop` | CPU / 内存 / 进程 | 系统级 + 进程级 | top 增强，交互式 |
| `iotop` | 磁盘 I/O | 进程级 | 定位 I/O 消耗大户 |
| `vmstat` | 内存 / 进程 / I/O / CPU | 系统级 | 高负载服务器低开销采样 |
| `pidstat` | CPU / 内存 / I/O / 上下文切换 | 进程级 | 精确到进程的资源分析 |
| `dstat` | 全维度 | 系统级 + 进程级 | 彩色实时综合监控 |
| `mpstat` | CPU（按核心） | 核心级 | 多核负载不均排查 |
