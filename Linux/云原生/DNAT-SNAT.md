在华为云VPC的网络环境中，NAT网关是实现内网与公网通信的关键服务，它主要包含SNAT和DNAT两种功能。简单来说，SNAT用于“出”，DNAT用于“入”。

### 📤 SNAT (源网络地址转换)

SNAT（Source Network Address Translation）的主要作用是让VPC内**没有公网IP**的云服务器能够**主动访问互联网**。

- **核心功能**：将云服务器发出的网络请求中的私有IP地址，替换为NAT网关绑定的弹性公网IP（EIP）。当互联网返回响应时，NAT网关再将响应转发给对应的云服务器。
- **主要价值**：
    1. **节省公网IP资源**：一个子网内的多台云服务器可以共享一个或多个弹性公网IP访问互联网，无需为每台服务器单独购买和绑定EIP。
    2. **增强安全性**：隐藏了VPC内部云服务器的真实私有IP地址，使其不直接暴露在公网上，有效防止了外部网络的直接探测和攻击。

**举个例子**：您VPC内有10台服务器需要定期从互联网下载系统更新。通过配置SNAT，这10台服务器可以共享1个弹性公网IP来完成下载任务，既经济又安全。

### 📥 DNAT (目的网络地址转换)

DNAT（Destination Network Address Translation）的主要作用是让VPC内**没有公网IP**的云服务器能够**被互联网用户访问**，从而对外提供服务。

- **核心功能**：将访问NAT网关弹性公网IP（EIP）的请求，根据预设的端口映射规则，转发到VPC内指定云服务器的指定端口上。
- **主要价值**：
    1. **对外提供服务**：使部署在内网的Web服务器、应用服务器等能够被公网用户访问。
    2. **灵活共享资源**：可以通过端口映射，让多个不同的内部服务（如Web服务和FTP服务）共享同一个弹性公网IP，通过访问不同的端口来区分。

**举个例子**：您有一台部署了网站的内网服务器（IP: 192.168.1.10，端口: 80）。通过配置DNAT，将弹性公网IP的80端口映射到这台服务器的80端口。这样，互联网用户访问该弹性公网IP时，就能顺利访问到您的网站。

### 核心区别总结

为了方便您理解，以下是SNAT和DNAT的核心区别：

| 功能       | 通信方向       | 核心作用               |
| :------- | :--------- | :----------------- |
| **SNAT** | VPC内 → 互联网 | 让内网服务器**主动访问**外网   |
| **DNAT** | 互联网 → VPC内 | 让内网服务器**被动接受**外网访问 |
