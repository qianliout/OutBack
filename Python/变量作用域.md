在 Python 中，**变量的作用域**（Scope）指的是变量在程序中可以被访问的范围。理解作用域是掌握 Python 编程的关键之一，它决定了在哪个位置可以读取或修改某个变量。

Python 遵循 **LEGB 规则** 来查找变量，这是变量作用域查找的顺序。下面我们详细解释这四个层级的作用域。

---

### 一、LEGB 规则

LEGB 是四个作用域的缩写，Python 在查找一个变量时会按照以下顺序进行：

1. **L: Local（局部作用域）**
2. **E: Enclosing（嵌套/闭包作用域）**
3. **G: Global（全局作用域）**
4. **B: Built-in（内置作用域）**

#### 查找顺序：`Local → Enclosing → Global → Built-in`

---

### 二、详细解释每个作用域

#### 1. L - Local（局部作用域）

- **定义**：函数内部定义的变量，只在该函数内部可见。
- **生命周期**：函数调用开始时创建，函数结束时销毁。
- **示例**：

```python
def my_function():
    x = 10  # x 是局部变量
    print(x)  # 可以访问

my_function()
# print(x)  # 错误！NameError: name 'x' is not defined
```

> 注意：在函数内部对变量赋值（`=`）默认创建局部变量，除非使用 `global` 或 `nonlocal` 声明。

---

#### 2. E - Enclosing（嵌套/闭包作用域）

- **定义**：指嵌套函数中，外层函数的局部作用域。
- **特点**：内层函数可以读取外层函数的变量，但不能直接修改（需要 `nonlocal`）。
- **示例**：

```python
def outer():
    y = 20  # y 在 outer 的局部作用域，也是 inner 的 enclosing 作用域

    def inner():
        print(y)  # 可以读取 enclosing 作用域的变量

    inner()

outer()  # 输出: 20
```

##### 修改 enclosing 作用域的变量

```python
def outer():
    y = 20

    def inner():
        nonlocal y  # 声明 y 是 enclosing 作用域的变量
        y = 30      # 修改外层变量
        print(f"inner: y = {y}")

    inner()
    print(f"outer: y = {y}")  # 输出: outer: y = 30

outer()
```

> 如果没有 `nonlocal y`，`y = 30` 会在 `inner` 函数中创建一个新的局部变量 `y`，不会影响外层的 `y`。

---

#### 3. G - Global（全局作用域）

- **定义**：在模块（`.py` 文件）顶层定义的变量，可以在整个模块中访问。
- **特点**：
  - 函数内部可以读取全局变量。
  - 要在函数内部修改全局变量，必须使用 `global` 关键字。
- **示例**：

```python
z = 40  # 全局变量

def func():
    print(z)  # 可以读取全局变量

func()  # 输出: 40
```

##### 修改全局变量

```python
counter = 0

def increment():
    global counter  # 声明要使用全局变量
    counter += 1

increment()
print(counter)  # 输出: 1
```

> 如果没有 `global counter`，`counter += 1` 会被解释为先读取 `counter` 再赋值，但局部作用域中还没有 `counter`，会报错。

---

#### 4. B - Built-in（内置作用域）

- **定义**：Python 内置的名称，如 `print`, `len`, `True`, `False`, `Exception` 等。
- **来源**：`builtins` 模块。
- **特点**：所有模块都可以访问这些名称。

```python
print("Hello")  # print 是内置函数
len([1, 2, 3])  # len 是内置函数
```

> 注意：你可以“覆盖”内置名称，但这是非常危险的做法：

```python
print = "Oops"  # 不要这样做！
# print("Hello")  # TypeError: 'str' object is not callable
```

### 三、作用域的实际查找过程

```python
x = "global"

def outer():
    x = "enclosing"

    def inner():
        x = "local"
        print(x)  # 输出: local

    inner()
    print(x)  # 输出: enclosing

outer()
print(x)  # 输出: global
```

如果 `inner` 中没有 `x = "local"`，它会向上查找：

```python
def outer():
    x = "enclosing"

    def inner():
        # x = "local"  # 注释掉
        print(x)  # 查找顺序: Local → Enclosing → Global → Built-in
                 # 找到 enclosing 的 x

    inner()

outer()  # 输出: enclosing
```

### 四、`global` 和 `nonlocal` 关键字对比

| 关键字 | 用途 | 适用场景 |
|--------|------|----------|
| `global` | 声明变量属于全局作用域 | 在函数中修改模块级别的变量 |
| `nonlocal` | 声明变量属于外层函数的局部作用域 | 在嵌套函数中修改外层函数的变量 |

```python
x = "global"

def outer():
    x = "enclosing"

    def inner():
        global x
        x = "modified global"
        # 这里修改的是全局的 x，不是 outer 的 x

    inner()
    print(x)  # 输出: enclosing（outer 的 x 没变）

outer()
print(x)  # 输出: modified global（全局 x 被修改）
```

### 五、命名空间（Namespace）与作用域的关系

Python 中每个作用域对应一个 **命名空间**（Namespace），它是一个从名字到对象的映射。

- **局部命名空间**：函数调用时创建，存储局部变量。
- **全局命名空间**：模块加载时创建，存储全局变量。
- **内置命名空间**：Python 启动时创建，存储内置名称。

你可以使用以下函数查看：

```python
def func():
    a = 1
    print(locals())   # 当前局部命名空间
    print(globals())  # 全局命名空间（整个模块）

func()
```

---

### 六、最佳实践与建议

1. **避免使用 `global`**：尽量通过函数参数和返回值传递数据，提高函数的可测试性和可维护性。
2. **合理使用闭包**：`nonlocal` 在实现闭包、装饰器、状态保持时非常有用。
3. **不要覆盖内置名称**：如 `list`, `str`, `print` 等。
4. **使用类封装状态**：对于需要共享状态的场景，优先使用类而不是全局变量。

---

### 七、总结

| 作用域 | 层级 | 定义位置 | 查找顺序 |
|--------|------|----------|----------|
| Local (L) | 最内层 | 函数内部 | 1 |
| Enclosing (E) | 中间层 | 嵌套函数的外层函数 | 2 |
| Global (G) | 外层 | 模块顶层 | 3 |
| Built-in (B) | 最外层 | Python 内置 | 4 |

记住：**赋值决定作用域**。在函数内部对变量赋值，默认创建局部变量，除非使用 `global` 或 `nonlocal` 显式声明。

理解 LEGB 规则和作用域机制，是写出清晰、可维护 Python 代码的基础。
