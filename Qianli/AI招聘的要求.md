### 智能体开发框架开发工程师

**岗位职责：**

1. 负责智能座舱 Agent 开发框架的整体架构设计与核心模块实现，提供包括意图解析、任务规划、工具注册与调用、状态管理、记忆机制等可复用的基础设施。
2. 设计并实现插件化的工具集成框架，支持业务方以声明式或注解方式快速接入座舱原子能力（导航、车控、媒体、语音、视觉等），并自动生成 API 文档与测试桩。
3. 开发 Agent 调试与可观测性平台，提供链路追踪（Trace）、交互日志、Prompt 版本管理、模拟环境运行等能力，提升 Agent 行为诊断与迭代效率。
4. 设计多 Agent 协作与编排引擎，支持顺序、并行、条件分支、循环等复杂工作流模式，并实现超时控制、降级策略与优先级调度。
5. 负责 Agent 框架的性能与资源优化，包括流式输出缓冲、并发请求池化、上下文窗口压缩、端云协同路由等，保障框架在车载嵌入式环境下的轻量与实时性。

**职位要求**  
**任职要求：**

1. 统招本科及以上学历，计算机、软件工程等相关专业，5年以上后端或框架开发经验，其中至少2年从事 Agent 框架或工作流引擎/规则引擎相关开发。
2. 精通 Python 或 C++，具备优秀的抽象与模块化设计能力，有开源框架（如 LangChain、Koog、Semantic Kernel、AutoGen等）源码阅读或二次开发经验。
3. 熟悉大模型应用范式（ReAct、CoT、Function Calling、RAG），能设计标准化的大模型接入适配层，支持不同推理后端（vLLM、TGI、OpenAI API、端侧推理引擎）的无缝切换。
4. 熟悉分布式系统设计中的异步消息、事件驱动、插件化架构，有实际的可扩展框架开发项目经验。
5. 具备良好的工程化思维，能够输出清晰的架构设计文档、API 规范及开发者指南，并辅导业务 Agent 开发工程师高效使用框架。
